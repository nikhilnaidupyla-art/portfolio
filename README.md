# My Portfolio Website

A modern, responsive personal portfolio website built using **HTML5**, **CSS3**, and **JavaScript** to showcase my software development projects, technical skillset, and contact information.

---

## 🌟 Key Features

- **Responsive Design**: Optimized for desktops, tablets, and mobile devices.
- **Modern Dark & Gold Aesthetic**: Clean dark theme with `#ffda00` gold accents and smooth hover animations.
- **Multi-Page Architecture**:
  - `Home`: Hero banner with quick links and CV download.
  - `About`: Professional summary and interactive skillset tags spanning Full Stack & GenAI.
  - `Projects`: Interactive project gallery with dynamic modal popups detailing system architecture and features.
  - `Contact`: Direct contact channels with mailto and telephone integration (`+91 7993740335`).

---

## 🚀 Featured Projects

1. **VizagBus AI — APSRTC Smart Transit System**
   - AI-driven public transit navigation and fleet telemetry platform for Visakhapatnam.
   - Built with **FastAPI**, **SQLite**, and **RAG (Retrieval-Augmented Generation)** using **Google Gemini** & **Groq Gemma**.
   - Features real-time GPS tracking across 70 stops, crowd density simulation, and automated grievance categorization.

2. **Pickleball Management System**
   - High-performance web application to manage tournaments, teams, and match statistics.
   - Built using **FastAPI**, **Python**, and **PostgreSQL**.

3. **Personal Portfolio**
   - Clean, modular personal showcase site built with modern responsive web standards.

## 💻 Installation & Local Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/nikhilnaidupyla-art/portfolio.git
   cd portfolio
   ```

2. **Open in browser:**
   ```bash
   # macOS
   open index.html

   # Windows
   start index.html

   # Linux
   xdg-open index.html
   ```
